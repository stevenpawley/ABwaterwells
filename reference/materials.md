# AWWID material codes to grain size estimates

AWWID material codes to grain size estimates

## Usage

``` r
materials
```

## Format

\## \`materials\` A data frame with 7,240 rows and 60 columns:

- material:

  AWWID material

- grainsize:

  Integer between 1 and 5 indicating the relative grainsize from fine to
  coarse. Descriptions that represent undescribed intervals are assigned
  a zero value.
